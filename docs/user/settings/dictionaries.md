## 随包词库

基础词库 13 万条，另有 11 本领域词库随包：法律、医学、地名、成语、诗词名句、IT、财经、饮食、动物、汽车、历史人物。
缺省只开启成语，其余在「设置 → 词库」勾选。领域词库只影响「是否有这个词」，不改变整句转换的权重。

基础词库收了 3.6 万个生僻字（规范字表以外的扩充汉字与台湾罕用字），用拼音能打出，排在同音字最后，不参与整句转换：
`fiao` 出 覅，`biangbiangmian` 出 𰻝𰻝面。系统字体没有的字会显示成方框。

## 导入用户词库

「设置 → 词库 → 导入词库」，接受三种格式：

- 青简 TSV：每行 `词<Tab>拼音<Tab>词频`，拼音音节间以空格分隔。
- Rime 的 `.dict.yaml`：读取名称和文件内的词条，词条须为 `词<Tab>拼音[<Tab>权重]`，拼音音节间以空格分隔，非整数权重按 1 处理。不支持 `import_tables` 引用的其他词库、自定义 `columns` 列顺序或 `.schema.yaml` 方案配置。
- 青简 `.qj`：他人制作的词库文件，自带名称与许可证。

TSV 与 Rime 词库导入时，`lue` / `nue` 自动统一为 `lve` / `nve`。词库用 `v` 表示 ü。
旧词库里写成 `lue` / `nue` 的词也照常能打。

导入后列在随包词库之下，显示名称、条数、许可证。可单独开关；「移除」只将文件移到一旁，不删除。

## 我的词

「设置 → 词库 → 我的词」列出输入法攒下的用户词：选过的生词、云端学到的词、自己新增的词。可以搜索、按拼音排序、核对读音，逐条编辑或删除。

- **新增 / 编辑**：填词和拼音。拼音可以连写（`qingjian`），切不开或有歧义时用空格或撇号隔开（`qing'jian`）；`ü` 写成 `v`（`nv`、`lve`）。
  词最长 32 个字符，至少要有一个汉字。编辑时点两下「删除」才删。
- **同音**：同一个读音有几个词时，列表里标「同音 N」，编辑时列出同音的其他词。
- **读音核对**：词在基础词库里也有、但读音不一样时标「读音不同」，筛选切到「读音核对」只看这些词；编辑时可以一键采用基础词库的读音。
  基础词库里没有的词（云端学来的、自造的）不参与核对。
- **导入 / 导出**：导入青简 TSV / TXT（每行 `词<Tab>拼音[<Tab>词频]`），逐行合并；导出把当前筛选与搜索出来的词写成同样的格式。
- **生效**：保存后输入法约一秒内重新载入；输入法没开时下次启动生效。输入法运行期间在别处改过词表时，页面会提示「重新载入」，保存时冲突不会覆盖文件。

删除只从用户词库移除。要连词频、选择次数这些学习记录一起清掉，仍在候选窗里找到这个词按 Shift + 数字。

## 导入后的词库

Windows 导入时会转换成 `.qj` 并自动启用，设置页显示导入条数或失败原因。没有可用词条的文件不能导入。
文件选择窗口支持按 Ctrl 或 Shift 多选，批量导入 YAML、TSV 或 `.qj`；单个文件失败不影响其余文件，完成后显示成功、失败数量及各文件结果。
输入法运行时通常在约一秒内自动加载；同名重新导入和移除也会自动更新，无需重启。
若手动编辑配置时出现格式错误，词库仍按上次有效的开关设置加载；修正配置后自动恢复应用新设置。
Rime 文件要经「导入词库…」转换，直接放进词库目录不会加载。
